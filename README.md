# AI Text Detector (v1)

An open-source, machine learning-powered AI text detection system that analyzes statistical predictability (perplexity) and sentence-level variance (burstiness) using GPT-2 to output a **calibrated probability (0–100%)** of AI authorship.

---

## 1. What It Does

Given any text passage, the detector extracts statistical and linguistic signals and predicts the exact probability that the text was generated by an AI model.

```json
{
  "ai_probability": 0.91,
  "label": "likely_ai",
  "tokens": 56,
  "warning": null
}
```

The system includes:
- A Python inference API (`predict_ai_probability`)
- A modular feature extraction pipeline (evaluating GPT-2 perplexity, sentence burstiness, token count, average sentence length, and type-token ratio)
- A calibrated probability model trained with 5-fold cross-validation
- An interactive **Streamlit web application** for real-time analysis

---

## 2. How It Works

Large language models (LLMs) like GPT-4, Claude, and Gemini generate text by selecting high-probability tokens sequentially from their learned distributions. This creates distinct statistical signatures compared to human writing:

### Key Signals

1. **Perplexity (Statistical Predictability)**:
   Measures how "surprised" a language model is by the text. Because AI models generate words that match typical token distributions, AI text exhibits **significantly lower perplexity** than human text.
   
   $$\text{PPL}(W) = \exp\left( -\frac{1}{N} \sum_{i=1}^N \ln P(w_i \mid w_{<i}) \right)$$

2. **Burstiness (Sentence-to-Sentence Variance)**:
   Humans naturally mix short, simple sentences with long, complex, and emotionally varied sentences. AI-generated text tends to maintain uniform sentence lengths and consistent probability flow. Burstiness is defined as the standard deviation of sentence-level perplexities:
   
   $$\text{Burstiness} = \sigma\left( [\text{PPL}(s_1), \text{PPL}(s_2), \dots, \text{PPL}(s_k)] \right)$$

3. **Linguistic Descriptors**:
   - **Type-Token Ratio (TTR)**: Vocabulary richness ($|V| / N$).
   - **Average Sentence Length**: Mean word count per sentence.
   - **Token Count**: Total length of the evaluated passage.

## 3. Results (Evaluated on Untouched Test Set)

The model was calibrated using `CalibratedClassifierCV` (sigmoid, 5-fold CV) on the training set and evaluated **once** on an isolated, balanced test set ($N=150$, 75 Human / 75 AI):

| Metric | Score |
|---|---|
| **Accuracy** | **96.67%** (145 / 150) |
| **ROC-AUC** | **0.9989** |
| **Recall (AI Detection Rate)** | **100.00%** (75 / 75 AI detected) |
| **Precision** | **93.75%** |
| **F1 Score** | **0.9677** |

### Confusion Matrix
- **True Negatives (Human detected as Human)**: 70
- **False Positives (Human detected as AI)**: 5
- **False Negatives (AI detected as Human)**: 0
- **True Positives (AI detected as AI)**: 75

## 4. How to Run

### Prerequisites
- Python 3.10+ (tested on Python 3.13)
- Git

### Installation

```bash
# 1. Clone repository
git clone https://github.com/CodeWithAnurup/ai-text-detector.git
cd ai-text-detector

# 2. Create virtual environment
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt
```

### Run Streamlit App

```bash
streamlit run app.py
```
Open `http://localhost:8501` in your browser.

### Python API Usage

```python
from src.predict import predict_ai_probability

result = predict_ai_probability("Your text passage here...")
print(result)
# Output:
# {'ai_probability': 0.84, 'label': 'likely_ai', 'tokens': 72, 'warning': None}
```

## 5. Limitations

- **False Positives on Formal & Academic Writing**: Highly formulaic human prose (legal briefs, technical documentation, scientific introductions) has lower perplexity and can occasionally be flagged as AI.
- **Non-Native English Writing**: Second-language English writing often relies on more common, predictable vocabulary, which may inadvertently reduce perplexity scores.
- **Short Texts (<50 tokens)**: Sample sizes under 50 tokens provide insufficient statistical data for stable perplexity estimation. The model returns a warning when input is under 50 tokens.
- **Heavily Paraphrased or Prompt-Engineered AI Text**: Inserting deliberate misspellings, colloquial slang, or running text through humanizers will elevate perplexity and evade detection.
- **Scoring LM (GPT-2)**: The base scoring model is GPT-2 (124M parameters). While lightweight and CPU-friendly, it differs in vocabulary and tokenization from newer frontier architectures.
